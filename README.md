# Orthogonal Frequency-Division Multiplexing Signal Using in Terhertz and 5G mmWave Communication System Experiment
Experimental Setup & System Overview
This repository contains the end-to-end OFDM Physical Layer (PHY) verification framework designed for ultra-high-speed communication experiments in 5G mmWave (28/39/60 GHz) and Sub-THz (e.g., 140/300 GHz) bands.

The system enables automated waveform generation, high-speed instrument control, and offline digital signal processing (DSP) utilizing a ultra-wideband hardware loop:

Transmitter (Tx): Tektronix AWG70001A (Arbitrary Waveform Generator) running at up to 50 GSa/s.

Receiver (Rx): Keysight Infiniium DSO-X 92504A (Digital Storage Oscilloscope) sampling at up to 80 GSa/s.
